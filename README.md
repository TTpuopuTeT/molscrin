## ✨ Что умеет сайт

- 🔍 **Поиск фильмов** с живыми карточками и постерами
- 🎬 **Страницы фильмов** — обложка, описание, жанры, возрастное ограничение
- 🖼 **Галерея кадров** — полноэкранный просмотр со свайпами
- 🎞 **Встроенный плеер** — автозапуск, остановка при закрытии
- 🎛 **Фильтры** — по жанру, возрасту, сортировка по дате и алфавиту
- 📱 **Адаптив** — корректно работает на телефоне, планшете и десктопе
- 🌌 **Живой фон** — движущиеся колонны из названий фильмов

## 📁 Структура
molscrin/

├── index.html ← главная

├── watch.html ← каталог фильмов с фильтрами

├── Split/ ← папка фильма «Раскол»

├── Spring/ ← папка фильма «Весна»

├── Ellie/ ← папка фильма «Элли»

├── ...остальные фильмы

└── README.md

Каждая папка фильма содержит страницу `*_film.html` и картинки (постер, фон, кадры).
