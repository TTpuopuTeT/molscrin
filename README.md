## ✨ Что умеет сайт

- 🔍 **Поиск фильмов** — с живыми карточками и постерами
- 🎬 **Страницы фильмов** — обложка, описание, жанры, возрастное ограничение
- 🖼 **Галерея кадров** — просмотр в полноэкранном режиме со свайпами
- 🎞 **Плеер трейлера** — встроенный, автозапуск при открытии
- 📱 **Адаптив** — корректно работает на телефоне, планшете и десктопе
- 🌌 **Живой фон** — движущиеся колонны из названий фильмов на главной

## 🛠 Технологии

- Чистый **HTML + CSS + JavaScript** — без фреймворков и сборщиков
- **GitHub Pages** для хостинга
- **GitHub Releases** для хранения видеофайлов (трейлеров)

## 📁 Структура
molscrin/
├── index.html ← главная страница
├── Split/ ← папка фильма «Раскол»
├── Spring/ ← папка фильма «Весна»
├── I_wont_cry_anymore/ ← папка фильма «Я больше не буду плакать»
├── An_eye_for_an_eye/ ← папка фильма «Око за око»
└── Dont_fly_away/ ← папка фильма «Не улетай»


Каждая папка фильма содержит:
- `*_film.html` — страница фильма
- `*.jpg` — постер для поиска и фон обложки
- `*_k1.jpg`, `*_k2.jpg` ... — кадры из фильма

## 🎬 Как добавить новый фильм

1. Создать папку с названием фильма на латинице
2. Положить туда страницу `*_film.html` по шаблону существующих
3. Добавить постер, фон и кадры
4. В файле `index.html` (и во всех страницах фильмов) добавить запись в `FILM_DATA`:
   ```js
   'Название фильма': {
     link:   'папка/название_film.html',
     poster: 'папка/постер.jpg'
   }

## Куда его положить

Файл `README.md` кладётся **в корень репозитория** — там же, где лежит `index.html`. GitHub сам подхватит его и покажет на главной странице репозитория.
